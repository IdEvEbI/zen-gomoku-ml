# 两阶段训练路线：强唐僧蒸馏 → 自对弈（草案）

> 与产品仓 [tang-seng-strength.md](https://github.com/IdEvEbI/zen-gomoku/blob/develop/docs/design/tang-seng-strength.md) 配套。  
> **先**上游把唐僧做硬并人机验收，**再**开本仓大规模数据与 R4。  
> 开源对照：junxiaosong / 飞桨 AlphaZero_Gomoku（规模预期）、whyb/Gomoku-AI（教师蒸馏 → MCTS）。

---

## 1. 为什么要两阶段

| 阶段       | 做法                                                              | 解决什么                            |
| ---------- | ----------------------------------------------------------------- | ----------------------------------- |
| 现 R2      | 弱/中等老师 JSONL + Policy CE + argmax                            | 管线；**不够可玩**（对猪八戒 ~12%） |
| **阶段 1** | **增强唐僧**（或同级搜索教师）产谱 / 软标签 → Policy(+Value) 蒸馏 | 快速「像强老师」                    |
| **阶段 2** | Policy+Value + **自对弈 MCTS**（R4）                              | 超越固定教师；推理仍建议带搜索      |

租高算力刷 **100 万局** 有意义的前提：标签尽量含搜索分布 / 胜负价值，且推理侧不只有 argmax。纯 CE 堆局数会撞天花板。

## 2. 依赖顺序（跨仓）

```txt
zen-gomoku: tang-seng-strength（威胁+评估）人机 OK
        ↓
zen-gomoku: 强唐僧 generate:teacher-records（开局 mixed / 花月浦月）
        ↓
zen-gomoku-ml: 小规模验证（1万～10万）蒸馏曲线 + vs 猪八戒
        ↓
（可选）租机放大；再开 R4 自对弈
        ↓
产品：AlphaZeroAgent = ONNX 先验 + 搜索（或 MCTS）
```

本仓 Backlog：**§8**（Policy+αβ）可与上游唐僧增强**并行原型**；大规模蒸馏标为 **§9**；自对弈 **§10 / R4**。

---

## 3. 阶段 1 — 唐僧教师蒸馏（Backlog §9）

### 输入

- 产品仓增强后的唐僧（或导出「搜索分布 π + 终局 z」若后续扩展 JSONL）。
- 短期可先用现有 JSONL（仅最优着法）做加强模仿；中期扩展为 soft π（推荐，对齐 whyb distill）。

### 本仓要做

- [ ] 文档：数据字段、与 `onnx-policy-v1` 兼容策略（Value 头若增加则契约升 `v2` 或双输出）
- [ ] 训练：支持 Value 头（或先 Policy-only 用强唐僧着法 CE）
- [ ] 评测：argmax vs Policy+αβ（§8）对猪八戒对照
- [ ] 规模阶梯：先 1万～1 0万验证，再考虑 ~10^5–10^6（算力另备）

### 非目标（§9）

- 不在本阶段实现完整 MCTS 自对弈。
- 不把沙和尚教师当主数据（难度梯度留给产品仓）。

---

## 4. 阶段 2 — 自对弈（Backlog §10 / R4）

- Policy+Value + MCTS 自对弈；对手池 / Elo 可选。
- 可从小棋盘课程（6×6 / 8×8）再升 15×15（junxiaosong / 飞桨建议）。
- 成功标准：擂台相对阶段 1 教师或相对猪八戒/人机体感明显提升；见产品仓 alphazero-lite R4。

---

## 5. 与 §8 的关系

| 项                 | 作用                                            |
| ------------------ | ----------------------------------------------- |
| §8 Policy+Minimax  | 立刻抬「现有弱 Policy」可用度；验证「搜索在外」 |
| §9 蒸馏            | 抬先验质量；教师来自强唐僧                      |
| 产品仓唐僧威胁搜索 | 人机最强古典线；兼教师                          |

三者不互斥：人机可继续用古典唐僧；小模型对手走 ONNX+搜索。
